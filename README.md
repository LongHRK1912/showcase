### Vault-X – Private Encrypted File Vault
<p align="center">
  <img src="media/vaultX.png" alt="Vault-X" width="140"/>
  <br><br>
  <a href="https://play.google.com/store/apps/details?id=com.hrk.vault_x">

  </a>
  <br><br>
  <img src="media/vaultXBanner.png" alt="Vault-X Banner" width="600"/>
</p>

**Absolute privacy. Military-grade encryption. Zero knowledge.**

Your photos, videos, documents and any files are encrypted with **AES-256-GCM** and stored only in Android's private internal storage — completely hidden from other apps and file managers.

**Privacy by design**  
✔ No tracking • No analytics • No accounts • No cloud by default  
✔ Developer cannot access your files — ever  
✔ Only you hold the key

#### Key Features
- Master Password + Biometric unlock (Fingerprint/Face)
- Auto-lock on exit or inactivity
- Unique per-file encryption keys
- Zero plaintext on disk
- Secure viewer with on-demand decryption
- Encrypted cloud backup (Google Drive • Dropbox • OneDrive)
- Secure delete with optional random-byte overwrite
- Full restore on reinstall using your Master Password

**Tech Stack**  
Kotlin • Jetpack Compose • AES-256-GCM • SQLCipher • Room • BiometricPrompt • Storage Access Framework

[Download on Google Play](https://play.google.com/store/apps/details?id=com.hrk.vault_x)
